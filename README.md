# Quem fica de fora do gov.br?

Pra subir precisa ter git e docker instalados.

```
git clone https://github.com/Ilhe8l/trabalho-informatica-sociedade.git
cd trabalho-informatica-sociedade
docker compose up --build
```

Depois é só abrir http://localhost:8080

Pra derrubar:

```
docker compose down
```
